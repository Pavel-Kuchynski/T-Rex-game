# Phase 2 Prompt: Core Game Engine

Implement only Phase 2 of the T-Rex game using the existing project skeleton.

## Scope
1. Implement game states: idle, running, paused, gameOver.
2. Build the main loop with requestAnimationFrame.
3. Add fixed or semi-fixed timestep logic for stable updates.
4. Implement reset, start, pause, and restart transitions.

## Rules
- Do not add player physics or obstacles yet.
- Keep state transitions explicit and easy to read.

## Deliverables
- Stable loop and deterministic update flow.
- State transitions work correctly.
