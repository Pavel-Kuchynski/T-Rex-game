# T-Rex Game Clone
## Description
This project is a clone of the popular T-Rex game that appears in Google Chrome when there is no internet connection. The game is implemented using JavaScript, HTML5 Canvas, and CSS. The player controls a T-Rex that must jump over obstacles to survive as long as possible.
## Technologies Used
- JavaScript
- HTML5 Canvas
- CSS
## Installation Instructions
1. Clone the repository: `git clone https://github.com/your-username/T-Rex-game.git`
2. Navigate to the project directory: `cd T-Rex-game`
3. Open `index.html` in a web browser to start the game.
## Run locally Instructions
1. Ensure you have a web browser installed (e.g., Chrome, Firefox).
2. Open the `index.html` file in your browser to run the game locally.
### Alternatively, you can use npx to run a local server:
1. Install `http-server` globally if you haven't already: `npm install -g http-server`
2. Navigate to the project directory: `cd T-Rex-game`   
3. Start the server: `npx http-server`
4. Open the provided URL (e.g., `http://localhost:8080`) in your web browser to play the game.
## Usage Instructions
- Press the spacebar to make the T-Rex jump.
- Avoid obstacles to keep playing and increase your score.
